# مركز إيواء اليرموك · V5

نظام ويب (PHP + MySQL) مبني فوق V4 مع الحفاظ على كل وحدات V4 (الملفات، المستفيدون، المالية، المستودعات، الترشيحات، الاستيراد والتصدير...).
الجديد في V5: صفحة دخول موحّدة وتصميم فاخر، بوابة للنازحين، بوابة للمؤسسات، ولوحات تحكم حسب الدور.

## التثبيت (XAMPP)
1. انسخ المجلد إلى `C:\xampp\htdocs\` وشغّل Apache وMySQL.
2. **قاعدة جديدة:** phpMyAdmin ← Import ← `database/schema.sql`.
   **قاعدة V4 موجودة:** اختر القاعدة ثم Import ← `database/migration_v5.sql` (آمن للإعادة، لا يحذف بيانات). خذ نسخة احتياطية قبلها.
3. عدّل `config.php` (كلمة مرور MySQL).
4. افتح `setup_admin.php` مرة واحدة (admin / 12803) ثم **احذفه**.
5. افتح `http://localhost/Yarmouk_Shelter_V5/login.php` وغيّر كلمة المرور.
6. (اختياري للتجربة فقط) `database/demo_seed.sql` ثم جرّب: هوية `900000001` وسنة `1985`.

> يلزم PHP 8.1 أو أحدث (XAMPP حديث). تأكد من تفعيل `pdo_mysql` و`mbstring`.

## الأدوار
| الدور | ماذا يرى ويفعل | نقطة الدخول |
|---|---|---|
| **المدير العام** (`admin`) | كل شيء + الحسابات والأدوار + الإعلانات + طلبات المؤسسات + الأرشيف | `login.php` ← متطوع |
| **مسؤول قطاع** | بيانات قطاعه فقط: الأسر، الإحصائيات، الترشيحات، الأرصدة، رسائل أسره، تقارير قطاعه | نفسه |
| **المالي** | المالية (إدخال/تعديل/تصدير) + اطلاع على المساعدات والمستودع والإحصائيات | نفسه |
| **الإغاثي** | التوزيعات والترشيحات والمساعدات والمستودع والترصيد + رسائل مشاكل الاستلام | نفسه |
| **مؤسسة شريكة** | طلب بيانات وإحصائيات مجمّعة ومتابعة الرد | يتحوّل تلقائياً لـ `institution.php` |
| **النازح** | حالة استلام اليوم، آخر الاستلامات، أفراد الأسرة، إرسال شكوى/اقتراح/استفسار | `login.php` ← أنا نازح |

إنشاء الحسابات: **الحسابات والأدوار** (المدير العام). اختيار الدور يطبّق الصلاحيات الجاهزة تلقائياً،
ويمكنك تعديلها بدقة بعدها من **المستخدمون والصلاحيات**. دور «متطوع» يترك الصلاحيات يدوية.

## تفاصيل مهمة
- **الترصيد:** يسجّل الإغاثي/المدير كمية الطرود المرصودة لكل قطاع. المتبقي = المرصود − عدد تسليمات نفس الطرد (نفس الاسم ونفس قطاع الاحتساب). استخدم كمية سالبة لتصحيح خطأ.
- **الأفراد في اللوحات الجديدة** تستثني: Shahid, Dead, Missing, Detained, Absent (نفس قاعدة عدّ الأسرة في V4). صفحة الإحصائيات القديمة ما زالت تعدّ كل السجلات، فقد تختلف الأرقام.
- **بيانات المؤسسات** مجمّعة فقط (بدون أسماء/هويات)، والأعداد الأقل من 5 تظهر `< 5`. المتطوع يرى الأرقام الفعلية.
- **قطاع مسؤول القطاع A** يشمل AS تلقائياً (وكذلك B/BS, C/CS, D/DS, S/S1).
- تصدير CSV في «التقارير» صار يُنظَّف من أي HTML قبل الإرسال.

## تحديث V5.1

### البحث المتقدم (`?page=search`)
- شريط بحث سريع في أعلى كل صفحة + صفحة فلاتر كاملة. البحث النصي يقبل عدة كلمات ويتجاهل الهمزات (أ/إ/آ) والتاء المربوطة والياء المقصورة والتشكيل والأرقام الهندية.
- **تصنيفات جاهزة بنقرة:** أيتام (الأب/الأم/الأبوين)، أرامل، مطلقات، مهجورات، أطفال، رضّع، كبار السن، ذوو إعاقة، أمراض مزمنة، جرحى، حوامل، مرضعات، أسر ترأسها نساء، أسر شهداء.
- **فلاتر مركّبة:** القطاعات، الجنس، العمر (سنوات/أشهر)، الحالة الاجتماعية، صلة القرابة، ربّ الأسرة، الضيافة، حجم الأسرة، حالة المنزل، الخيمة ونوعها وحالتها، المنطقة، المهنة، وجود هاتف، تاريخ الإضافة، وسجل الاستلام (استلمت خلال فترة / لم تستلم أبداً / لم تستلم منذ تاريخ) بحسب نوع المساعدة.
- الجمع بين التصنيفات: «كلها معاً» أو «أي واحد».
- عرض أفراد أو أسر، ترتيب، ترقيم صفحات، طباعة، وتصدير CSV لكل النتائج (بصلاحية التصدير، والهوية/الهاتف تُخفى لمن لا يملك البيانات الحساسة).
- **تعريف اليتيم:** طفل أقل من 18 (ابن/ابنة) في أسرة فيها أحد الوالدين (الزوج/الزوجة) متوفى أو شهيد. الشهداء والمتوفون والمفقودون والمعتقلون والغائبون مستثنون افتراضياً من النتائج، ويمكن تضمينهم بخيار.
- أرقام بطاقات الداشبورد هي نفس نتائج صفحة البحث تماماً (نفس الشروط).

### الداشبورد الجديد
رسوم SVG تُرسم من الخادم (تعمل بدون إنترنت): دونات للجنس والحالة الاجتماعية والشكاوى، عدّاد تغطية المساعدات، هرم عمري، خط التسليمات اليومية لآخر 30 يوماً، أعمدة مالية لـ6 أشهر، أرصدة المستودع، 14 بطاقة للفئات الأكثر احتياجاً، وخط زمني للنشاط. مسؤول القطاع والمالي والإغاثي لهم رسوم خاصة بنطاقهم. الصورة الرئيسية رسم SVG لمخيم؛ إن أردت صورة حقيقية ضعها في `assets/` وأخبرني لأربطها.

### حساب المالك
شغّل `database/owner_account.sql` بعد الترحيل لإنشاء المستخدم `yarmouk.owner` بدور المدير العام (يحتوي على تجزئة bcrypt فقط، لا كلمة المرور نفسها). كلمة المرور مكتوبة في محادثتنا، **فغيّرها من الحسابات والأدوار** بعد أول دخول.
