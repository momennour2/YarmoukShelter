## المطلوب منك (بالترتيب)
1. من لوحة Clever Cloud: غيّر كلمة سر القاعدة (أو أنشئ مستخدماً جديداً بأقل صلاحيات).
2. في Vercel → Settings → Environment Variables: أضف DB_HOST و DB_NAME و DB_USER و DB_PASS، ثم أعد النشر.
3. بعد نجاح الدخول، احذف القيم القديمة من api/config.php (الجزء بعد `?:`).
4. غيّر كلمة سر admin.
5. شغّل security_test.sh وأرسل لي النتيجة.
6. (اختياري، تغيير كبير) تنظيف تاريخ git بـ git filter-repo. بعد تغيير الكلمة تصبح القديمة بلا قيمة، فلا داعي له غالباً.
